# 807 班級看板

## 上傳到 Netlify

1. 登入 Netlify 並新增專案，選擇此資料夾或連接 Git 儲存庫。
2. Netlify 會安裝專案所需套件並部署資料儲存功能。
3. 完成後，主網址會開啟班級看板；教師管理頁網址為 `https://你的網站名稱.netlify.app/teacher.html`。

## 教師管理登入

- 使用者名稱：`teacher`

請先在 Netlify 的 **Project configuration → Environment variables** 新增以下兩項，再部署：

- `ADMIN_USERNAME`：教師帳號，例如 `teacher`
- `ADMIN_PASSWORD`：教師強密碼
- `SUBMIT_PASSWORD`：任課教師／小老師在公開看板新增「明日事項」使用的填寫密碼；建議另設一組。未設定時，系統會暫時使用教師密碼。

教師頁會使用這組帳密連接雲端資料。若使用 Netlify Pro／Enterprise，也可在 `_headers` 將 `Basic-Auth:` 後方改成相同帳密，讓教師頁在載入前就被 Netlify 保護。請勿將含有密碼的原始檔公開到 GitHub 等公開位置。

這個密碼規則使用 Netlify 的 Basic Authentication，僅適用於支援該功能的 Netlify Pro 或 Enterprise 方案。

## 名單批次上傳與人數設定

- 在教師頁的「座號與學生名單」可直接批次貼上「座號,姓名」，每行一位；也支援從試算表貼上以 Tab 分隔的兩欄資料。缺少的座號不會被建立為學生。
- 座位顯示的人數會自動依實際名單計算，不需要另外設定。
- 午餐小組可在教師頁選擇工作項目後，設定該項目的「此項目人數」；每個項目都能使用不同名額。

## 座位與午餐小組

- 教師頁的座位表固定為六排、每排五位，可直接拖拉學生方塊來交換座位或拖到未排座區。
- 午餐工作項目會以不同顏色按鈕完整列出；選取學生後，學生方塊會變成該工作項目的顏色。

## 資料同步說明

班級資料會儲存在 Netlify Blobs。老師儲存名單、課表、任務、座位、值日生、打掃與午餐分工後，看板會在約 20 秒內自動取得最新資料；重新部署網站也不會清除這些資料。

## 今日任務、明日事項與紀錄

- 公開看板的「明日事項」可由任課教師或小老師輸入填寫密碼後新增，並可加上手寫筆跡。
- 公開看板的「課程任務」可由任課教師或小老師輸入同一組填寫密碼新增任務；輸入密碼後，點選學生小卡即可切換該任務的完成狀態。
- 系統以台灣日期判斷隔日：下一次有人開啟看板時，明日事項會自動移入今日任務、明日事項清空，原本今日任務則歸檔。
- 在「明日事項」頁面可選擇日期查閱已歸檔的任務。

第一次啟用雲端儲存時，請在原本已有班級資料的電腦開啟 `teacher.html` 並登入一次；系統會將該電腦原有資料上傳為雲端初始資料。
